# Lab Website

This is a static website for our research lab.

## Running Locally

You can run this website locally using any of the following methods:

### Option 1: Open directly in a browser

Simply open the `index.html` file in your web browser:

```bash
xdg-open index.html
```

### Option 2: Use Python's built-in HTTP server

If you have Python installed, you can serve it locally:

**Python 3:**
```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000 in your browser.

### Option 3: Use Node.js http-server

If you have Node.js installed:

```bash
npx http-server -p 8000
```

Then visit http://localhost:8000 in your browser.
